# Keyboard shortcuts

| Shortcut | Action |
| --- | --- |
| `Ctrl+N` | New note |
| `Ctrl+P` | Quick switcher |
| `Ctrl+Shift+F` | Search all notes |
| `Ctrl+Shift+E` | Export the current notebook |
| `Ctrl+Enter` | Save and close the editor |
| `Alt+←` / `Alt+→` | Back and forward through recent notes |

## Editing

```text
Ctrl+B   bold
Ctrl+I   italic
Ctrl+K   insert link
Ctrl+/   toggle a task checkbox
```

## Tips

- Hold `Ctrl` while clicking a note to open it in a new tab.
- Use `Esc` to leave the quick switcher without opening anything.
